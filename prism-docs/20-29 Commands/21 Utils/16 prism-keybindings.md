# `prism-keybindings`

A helper utility that queries [[01 Hyprland]] for a searchable list of loaded keybindings. It presents these bindings using [[08 Rofi]], including bindings generated by Lua and excluding archived configuration files.

## How it works

1. **Query:** The script reads the running compositor's bindings with `hyprctl binds -j`.
2. **Formatting:** It uses `jq` to decode modifier keys and display each shortcut with its description, falling back to its dispatcher and argument when no description is set.
3. **Display:** The processed list is piped into `rofi -dmenu`, creating a searchable window where users can type keywords (like "browser" or "volume") to see the associated hotkeys.

**Dependencies**

- `rofi`: Displays the keybinding list.
- `hyprland`: Provides `hyprctl`.
- `jq`: Formats the compositor's JSON output.
- `libnotify`: Reports when no bindings are available.

## Usage 

This script is bound to a key so help is always accessible.

```bash
prism-keybinds
```
